# 🏰 Cửu Chương Voxel Phép Thuật — Bé Mai Nhiên

Ứng dụng học tập tương tác bảng cửu chương (nhân và chia 1–10) phong cách **Roblox & Minecraft Voxel (Adopt Me Aesthetic)** dành riêng cho học sinh lớp 3, bé **Mai Nhiên**.

---

## 🌟 Tính Năng Nổi Bật

1. **🏝️ Đảo Bay Mai Nhiên (Skyblock Tycoon)**:
   - Bé giải toán kiếm **Ngọc Lục Bảo (Emeralds)** và **Kim Cương (Diamonds)** để mở khóa các công trình kỳ vĩ: *Cối xay gió bánh kẹo, Vườn anh đào khối hộp, Tháp ngọc lục bảo, Lâu đài pha lê, Cầu vồng kỳ lân*.
2. **🌸 Vườn Khám Phá (Visual Arrays & Number Line)**:
   - Trực quan hóa bản chất phép nhân bằng **Mảng Khối Hộp (Grid Matrix)** (bấm vào từng hàng để đếm nhảy) và **Trục Số Bước Nhảy (Number Line Jump)** của thú cưng.
3. **🧪 Phòng Luyện Bảng Chuyên Sâu**:
   - Tự do luyện tập 10 bảng nhân và 10 bảng chia.
   - Luân phiên giữa **Bàn Phím Số Ma Thuật Voxel (Big Touch Numpad)** và **Bong Bóng Kẹo Ngọt Trắc Nghiệm**.
   - Đo lường **Tốc độ tia chớp (< 3s)** thưởng Kim Cương.
4. **⚡ Đường Chạy Obby Cửu Chương (Roblox Parkour Jump)**:
   - Nhảy bục vượt chướng ngại vật trên mây với 4 Tầng Danh Vọng:
     - 🥉 **Tầng Đồng**: Bảng 2, 5
     - 🥈 **Tầng Bạc**: Bảng 3, 4, 6
     - 🥇 **Tầng Vàng**: Bảng 7, 8, 9
     - 💎 **Tầng Kim Cương**: Tổng hợp 1-10 + Phép chia có dư
5. **🩹 Sổ Tay Lỗ Hổng (Hàn Gắn Khối Nứt)**:
   - Tự động gom các phép tính bé từng bấm sai hoặc phản xạ chậm để lặp lại ngắt quãng (Spaced Repetition) kèm gợi ý thông minh từ bạn thú cưng.
6. **🛠️ Xưởng Chế Tạo & Bạn Đồng Hành Voxel**:
   - Chọn và đặt tên cho thú cưng: 🐰 **Thỏ Bông**, 🐱 **Mèo Mun**, 🐶 **Cún Vàng**, và 🦄 **Kỳ Lân Cầu Vồng Huyền Thoại**.
   - Mua sắm trang phục (nón phù thủy, cánh tiên bướm, vương miện hoàng gia) và đồ trang trí đảo bay.

---

## 🚀 Khởi Chạy Ứng Dụng

```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển (Dev)
npm run dev

# Đóng gói xuất bản (Build)
npm run build
```

Mở trình duyệt tại: **`http://localhost:5174/`**
- Hỗ trợ cài đặt PWA ngoại tuyến lên iPad/Tablet chỉ với 1 chạm.
